# Contributing to OTUS Kubernetes Course

Спасибо за интерес к улучшению материалов курса!

## 🤝 Как внести вклад

1. Форкните репозиторий
2. Создайте ветку для ваших изменений (`git checkout -b feature/amazing-feature`)
3. Зафиксируйте изменения (`git commit -m 'Add some amazing feature'`)
4. Отправьте в ветку (`git push origin feature/amazing-feature`)
5. Откройте Pull Request

## 📝 Стандарты

- Используйте понятные имена коммитов
- Добавляйте документацию к новым функциям
- Тестируйте ваши изменения локально
- Следуйте существующему стилю кода

## 🐛 Сообщение об ошибках

Используйте GitHub Issues для сообщения об ошибках с подробным описанием.
